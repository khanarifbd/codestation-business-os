It maps the recovered original V2 report's entire Appendix A (160 unique IDs) to the local test sources and limits. Original statuses are historical live-browser observations, not the status of the amended branch. No pushes, deployments, production changes, or real payments/emails were performed by this audit.

- A linked existing module script is **related coverage**, not evidence every assertion in the original scenario is covered. Where there is no dedicated exact regression, the original UI observation remains the only exact scenario evidence located. Do not change an original PASS/FAIL/BLOCKED/PARTIAL to a current PASS from this mapping alone.

### Evidence levels

| Code | What it proves | What it does not prove |
|---|---|---|
| D | Real local PostgreSQL with direct application/service/route-function calls and assertions | HTTP routing, request parsing, middleware/authentication, browser state and rendering |
| H-app | TestClient HTTP through the real application routes, authentication, tenant dependencies and request parsing with real PostgreSQL; only get_db rebound to rollback fixtures | Real TCP/proxy stack, login issuance, browser behavior or production deployment |
| D-related | Related direct-function module assertions, often with different fixtures | Exact original case or all original guards/values/UI actions |
| M | Isolated database migration fixture and invariant checks | Production upgrade safety or actual release migration |
| S | Source-content assertions | Rendered wording/layout or user comprehension |
| R | Rendered actual React component or isolated formatter/eligibility unit | Full page integration, real server errors, downloaded file or browser accessibility audit |
| B-mock | Real Chromium UI with intercepted synthetic domain responses; login is real | Actual domain endpoint behavior, database writes, transaction atomicity or side effects |
| B-real | Browser against real local application API | All actions in the test title; inspect actual assertions |
| D+response | Direct upload/download function plus streamed ASGI response bytes | Authenticated application HTTP route or browser download |
| D+HTTP-adapter | Direct upload/download function, then returned response served by synthetic TestClient `/download` | Actual application's route/dependencies/middleware or live/browser download |
| related / original UI only | Existing module suite is a relevant starting point; exact case replay not established | Current exact case pass |
| policy | Observed behavior is reproduced or documented, but expected behavior is undecided | Correctness of a convention that has not been specified |
